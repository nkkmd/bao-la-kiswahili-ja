# 正式版リリースロードマップ

> 対象リリース: `v1.0.0`
>
> 現在の基準版: `v0.1.0-draft`

## 目的

この文書は、ドラフト版を正式版 `v1.0.0` として公開するまでの条件と作業順序を管理する。

プロジェクトの制作工程と長期的な構想は [ROADMAP.md](ROADMAP.md)、個別の未解決事項は [TODO.md](TODO.md)、資料照合と外部レビューの記録は [REVIEW.md](REVIEW.md) で管理する。

## 正式版の位置づけ

`v1.0.0` は、Bao la Kiswahili（ザンジバル版）について、本書が採用する規則、資料間の差、未確定事項を読者が区別でき、日本語のルールブックとして一貫して通読できる版とする。

正式版は、すべての地域差や研究上の疑問が解消されたことを意味しない。解消できない論点は、採用判断、根拠、適用範囲を明記する。根拠を確認できない内容は、正式ルールとして断定しない。

## リリース判定の区分

各作業は次の区分で判定する。

- **必須**: 未完了の場合は `v1.0.0` を公開しない
- **推奨**: 可能な限り正式版へ含めるが、未完了理由と今後の扱いを明記すれば延期できる
- **将来課題**: 正式版公開後の改訂で扱える

## 正式版以後の候補

次の項目は、Phase 1で正式版へ含めると決定しない限り、公開後の改訂候補とする。

- 実戦棋譜に基づく局面例の継続的な追加
- ザンジバル版の定跡と局面評価の検証
- nyumba、kichwa、kimbiと勝率の関係の研究
- GitHub Pages、PDF、EPUB、印刷版のうち `v1.0.0` に含めなかった形式
- 英語版、スワヒリ語版、対話型ルールブック、学習アプリ

## 進捗更新のルール

- 作業を完了したらチェックボックスとPhaseの状態を更新する
- 判断の根拠は `docs/REVIEW.md`、未解決事項は `docs/TODO.md` に記録する
- 正式版の範囲や必須条件を変更した場合は、変更理由をこの文書と `docs/CHANGELOG.md` に残す
- Phaseは基本的に順番に進めるが、資料探索、レビュー依頼、公開形式の検証は並行してよい

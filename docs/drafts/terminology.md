# 用語一覧（Phase 1草稿）

## 記録方針

- 状態: 調査中
- 確認日: 2026-06-28
- 定義の中心資料: `docs/REFERENCES.md` のR-002

日本語説明は暫定である。R-001との照合後、確定した内容を `guide/04-glossary.md` へ移す。

| 用語 | 暫定的な説明 | 状態・注意 |
| --- | --- | --- |
| Bao la Kiswahili | 東アフリカで行われるBaoの複雑なルール系統。本書ではザンジバル版を中心に扱う | 対象範囲を調査中 |
| shimo / mashimo | 盤の穴。単数形／複数形 | R-001で綴りと語義を再確認 |
| kete | 盤上で蒔く同一の駒 | 「種」「石」等の日本語総称は未決定 |
| nyumba | 各プレイヤーの前列にある特別な穴 | 「家」は補助訳候補。所有状態と例外規則がある |
| kichwa | 各前列の左右端の穴 | R-002の `kitchwa` は異綴りとして要確認 |
| kimbi | 各前列でkichwaの隣にある穴 | kichwaとともに捕獲後の蒔き始めへ影響する |
| namua | 手元に残した駒を1手ごとに盤へ入れる前半段階 | R-002で確認。日本語補助訳は未決定 |
| mtaji | すべての駒が盤上へ入った後半段階 | R-002で確認。日本語補助訳は未決定 |
| capture | 相手前列の向かい合う穴から駒を取り、自分側で蒔き直す処理 | 日本語は「捕獲」を暫定採用 |
| sowing | 駒を連続する穴へ1個ずつ置く操作 | 日本語は「蒔き」を暫定採用 |
| relay sowing | 蒔き終わりの穴から駒を取り上げ、蒔きを継続する仕組みの一般的な英語表現 | R-002では継続を `endelea` と呼ぶ |
| endelea | 条件を満たす蒔き終わりの穴から、同方向へ蒔きを継続すること | 正確な成立・停止条件は規則章で整理する |
| takasa | 捕獲から始まらず、その手では捕獲を行わない手 | `takata` と混同しない |
| takasia | mtajiで、一定条件下の相手穴を空にできなくする特殊規則 | 正確な日本語説明は局面例の作成後に確定 |
| takata | 現在の標準用語候補に含まれるが、今回の中心資料では未確認 | 語形・意味・出典を要調査 |
| marker | 意味と出典を未確認 | 正式用語として採用しない |
| taxation | 意味と出典を未確認 | 正式用語として採用しない |

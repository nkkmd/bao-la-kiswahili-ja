# 表記・用語ガイド

## 基本方針

- 読者は、初めて Bao la Kiswahili に触れる日本語話者を想定する。
- 初心者向け説明、正式ルール、具体例、注意点、地域差を区別する。
- 確認済みの事実、資料に基づく解釈、未確認事項を混同しない。
- ルールを断定するときは、`docs/REFERENCES.md` または調査メモへたどれるようにする。

## 標準用語

次の語は原則として原語を維持する。

- Bao la Kiswahili
- namua
- mtaji
- nyumba
- takata
- kichwa
- kimbi
- relay sowing

`capture` は「捕獲」、`sowing` は「蒔き」を暫定的な日本語表記とする。

日本語の補足は初出時または用語辞典で示す。最終的な語義と表記は、資料調査後に `guide/04-glossary.md` と同期する。

## 日本語表記

- 文体は「です・ます」調を基本とする。
- 一文を短くし、手順と成立条件を分ける。
- 数字は算用数字を用いる。
- 原語は半角英字で表記する。
- 未確定の訳語には「暫定」と明記する。

## 見出しと章構成

各章は内容に応じて、次の順序を基本とする。

1. 初心者向け説明
2. 正式ルール
3. 具体例
4. 注意点
5. 地域差
6. 参考文献または確認メモ

短い草稿では空見出しを並べず、必要な課題を `docs/TODO.md` に記録する。

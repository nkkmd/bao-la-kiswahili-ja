# Bao la Kiswahili 日本語完全ガイド

完成する日本語ガイド本文を置く。章構成とファイル名は `docs/ROADMAP.md` に従う。Phase 4では、ザンジバル版本編に当たる第00章〜第10章の初稿を作成した。Phase 5では、規則確認用の部分局面を32例追加した。Phase 6では、用語辞典を40項目へ拡充した。Phase 7ではFAQを50問へ拡充し、Phase 8では戦術学習と分析方法を初級・中級・上級に分けて執筆した。第11章は、追加資料を確認してから確定する。

## 読む順序

初めて学ぶ読者は、`01-introduction.md` から `10-endgame.md` まで順に読む。用語だけを確認したい場合は `04-glossary.md`、簡略版で練習したい場合は `11-kujifunza.md` を参照する。

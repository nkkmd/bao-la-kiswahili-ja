# 規則確認用の局面例

この実例集は、Bao la Kiswahili（ザンジバル版）の規則を1項目ずつ確認するためのものです。実在の対局を採録した棋譜ではありません。R-002とR-003から直接導ける条件を説明するため、本プロジェクトが構成した部分局面です。

## 読む前の注意

- 図にない穴は「空」ではなく「未指定」です。
- `A4=2`は、Southの前列A4にketeが2個あることを表します。
- `A4=2 ↔ a4=3`は、向かい合う前列穴の個数を表します。
- `A3=2 → A4=1 → A5=1`は、A3から選んだ方向へ蒔く順序を表します。
- `手元=1+`は、手番プレイヤーの手元に1個以上残っていることを表します。
- 明記しないかぎり、図示した判定を妨げる別の強制手はないものとします。
- これらは局所的な規則の確認例です。完全な盤面の到達可能性や戦術的な良し悪しは主張しません。

## 根拠状態

| 表示 | 意味 |
| --- | --- |
| A | R-002とR-003で骨格が一致する規則 |
| B | R-002の形式規則で確認した細則。R-001本文との照合待ち |

根拠記号は[参考文献](../../docs/REFERENCES.md)に対応します。Bの例は「ザンジバル版一般に普遍的な規則」としてではなく、本書が採用する暫定基準の確認用として掲載します。

## 盤・座標・初期配置

### E01: 各プレイヤーが使う2列

- 部分局面図: `North: b列・a列 / South: A列・B列`
- 判定: Northは`a`と`b`、Southは`A`と`B`だけへ蒔きます。中央側の`a`と`A`が前列です。
- 根拠状態: A
- 根拠: R-002, pp. 163–164、R-003, Issue 4, p. 21。

### E02: 特別な穴の座標

- 部分局面図: `South: A1 [A2] A3 A4 {A5} A6 [A7] A8`
- 判定: A1・A8がkichwa、A2・A7がkimbi、A5がnyumbaです。North側は小文字の対応座標です。
- 根拠状態: A
- 根拠: R-002, pp. 163–164、R-003, Issue 4, p. 21。

### E03: Southの初期配置

- 部分局面図: `A1..A8 = [0, 0, 0, 0, 6, 2, 2, 0] / B1..B8 = すべて0 / 手元=22`
- 判定: nyumbaのA5に6個、本人から見て右隣のA6・A7に2個ずつ置きます。
- 根拠状態: A
- 根拠: R-002, pp. 165–166、R-003, Issue 4, p. 21。

### E04: Northも本人から見た右へ置く

- 部分局面図: `a5=6, a6=2, a7=2 / b列=すべて0 / 手元=22`
- 判定: Northも本人の視点で右隣へ置きます。紙面を見る観察者の右を基準にしません。
- 根拠状態: A
- 根拠: R-002, pp. 165–166、R-003, Issue 4, p. 21。

## namua

### E05: namuaの捕獲可能穴

- 部分局面図: `A4=2 ↔ a4=3 / 手元=1+`
- 判定: A4とa4がともに占有されているため、Southは手元から1個をA4へ入れてa4を捕獲できます。
- 根拠状態: A
- 根拠: R-002, p. 166、R-003, Issue 4, pp. 21–22。

### E06: 捕獲候補が複数ある

- 部分局面図: `A3=1 ↔ a3=2`、`A6=4 ↔ a6=1 / 手元=1+`
- 判定: A3とA6はどちらも捕獲候補です。捕獲義務はありますが、この2候補のどちらを選ぶかは手番プレイヤーが決めます。
- 根拠状態: A
- 根拠: R-002, pp. 165–166、R-003, Issue 4, pp. 21–22。

### E07: 真向かいが空なら捕獲できない

- 部分局面図: `A4=2 ↔ a4=0 / 手元=1+`
- 判定: 自分のA4が占有されていても、a4が空なのでA4から捕獲はできません。
- 根拠状態: A
- 根拠: R-002, pp. 164, 166。

### E08: 自分側が空でも捕獲できない

- 部分局面図: `A4=0 ↔ a4=3 / 手元=1+`
- 判定: a4にketeがあっても、自分のA4が空なので、手元の1個をA4へ入れて捕獲することはできません。namuaの捕獲開始穴は、入れる前から占有されている必要があります。
- 根拠状態: A
- 根拠: R-002, p. 166。

### E09: 捕獲不能時のtakata

- 部分局面図: `A4=2 ↔ a4=0 / 手元=1+ / 他に捕獲候補なし`
- 判定: 手元から1個をA4へ入れます。A4は3個になり、その3個を選んだ方向へ蒔いてtakataを続けます。
- 根拠状態: A
- 根拠: R-002, pp. 165–166、R-003, Issue 5, pp. 22–23。

### E10: namuaは後列から始めない

- 部分局面図: `B4=3 / 手元=1+ / 捕獲候補なし`
- 判定: B4に複数のketeがあっても、namuaのtakataをB4から始めることはできません。開始穴は前列から選びます。
- 根拠状態: B
- 根拠: R-002, p. 166。

### E11: 1個だけの穴を選べない場合

- 部分局面図: `A3=1, A6=2 / 捕獲候補なし / 所有中nyumbaなし`
- 判定: A6のような2個以上の前列穴があるため、A3からtakataを始めることはできません。
- 根拠状態: B
- 根拠: R-002, p. 166、R-003, Issue 5, pp. 22–23。

### E12: 1個だけの穴を選べる例外

- 部分局面図: `A3=1, A6=1 / 前列の他穴=0 / 捕獲候補なし`
- 判定: 前列に2個以上の穴がないため、1個だけの占有穴からtakataを始められます。
- 根拠状態: B
- 根拠: R-002, p. 166。

### E13: 所有中のnyumbaから通常開始しない

- 部分局面図: `{A5=6 所有中}, A6=2 / 捕獲候補なし`
- 判定: A6という別の占有穴があるため、6個以上ある所有中のA5からtakataを始めることはできません。
- 根拠状態: A
- 根拠: R-002, p. 166、R-003, Issue 5, pp. 22–23。

### E14: nyumbaだけが前列に残った場合

- 部分局面図: `{A5=6 所有中}, 前列の他穴=0 / 手元=1+ / 捕獲候補なし`
- 操作図: `手元からA5へ1個 → A5=7 → A5から2個だけ取って左右へ蒔く`
- 判定: 全7個ではなく2個だけを蒔き、A5に5個残します。6個以上を条件とする機能は働かなくなります。R-002・R-008では所有状態自体は失われず、再び6個以上になれば条件付きの機能が戻ります。R-003 Issue 5では、この5個の穴を機能するnyumbaとは呼びません。
- 根拠状態: B
- 根拠: 操作はR-002, p. 166、R-003, Issue 5, pp. 22–23、R-008, §§2.3.2, 4.2.1.3。mtajiへの持ち越しは資料差として未解決。

## mtaji

### E15: mtajiへの移行

- 部分局面図: `South手元=0 / North手元=0`
- 判定: 両者の手元のketeが盤上へ入り終わるとmtajiです。以後は手元から1個を加えません。
- 根拠状態: A
- 根拠: R-002, pp. 166–167、R-003, Issue 4, p. 22。

### E16: 開始穴の全内容を取る

- 部分局面図: `B3=4`
- 操作図: `B3から4個すべて取る → 選んだ方向の次の4穴へ1個ずつ`
- 判定: 1個だけを動かすのではなく、開始穴の全keteを蒔きます。
- 根拠状態: A
- 根拠: R-002, p. 167、R-003, Issue 4, p. 22。

### E17: 1個だけの穴から始められない

- 部分局面図: `A3=1`
- 判定: mtajiではA3から手を始められません。開始穴には2個以上必要です。
- 根拠状態: B
- 根拠: R-002, p. 167。

### E18: mtajiで最初の蒔きから捕獲する

- 部分局面図: `A3=2, A4=1, A5=1 ↔ a5=3`
- 操作図: `A3の2個を右へ: A4へ1個 → A5へ1個`
- 判定: 最後の1個が占有されていたA5へ入り、真向かいのa5も占有されているため、a5の3個を捕獲します。
- 根拠状態: A
- 根拠: R-002, pp. 164, 167、R-003, Issue 4, p. 22。

### E19: 捕獲手があればtakataを選べない

- 部分局面図: `E18の捕獲手あり / B6=4からは捕獲なし`
- 判定: B6からのtakataではなく、捕獲に至る開始穴と方向を選ばなければなりません。
- 根拠状態: A
- 根拠: R-002, pp. 165, 167、R-003, Issue 4, pp. 21–22。

### E20: 16個の穴は捕獲手の開始穴にしない

- 部分局面図: `B3=16`
- 判定: R-002の形式規則では、mtajiの捕獲手は2個以上15個以下の穴から始めます。B3を最初の捕獲手の開始穴にはできません。
- 根拠状態: B
- 根拠: R-002, p. 167。

### E21: takataは可能なら前列から始める

- 部分局面図: `A4=2, B4=5 / 捕獲手なし`
- 判定: 前列A4から合法にtakataを始められるため、後列B4を選びません。
- 根拠状態: B
- 根拠: R-002, p. 167。

### E22: mtajiで合法手がない

- 部分局面図: `自分のA列・B列の全16穴が0個または1個`
- 判定: 2個以上ある開始穴がないため、手番プレイヤーは敗北します。
- 根拠状態: B
- 根拠: R-002, pp. 164, 167。

## 捕獲方向

### E23: 左のkichwa・kimbiでの捕獲

- 部分局面図: `捕獲穴=A1またはA2`
- 判定: 捕獲したketeは左のkichwa A1から蒔き始め、時計回りに進みます。
- 根拠状態: A
- 根拠: R-002, pp. 164–165、R-003, Issue 4, pp. 21–22。

### E24: 右のkichwa・kimbiでの捕獲

- 部分局面図: `捕獲穴=A7またはA8`
- 判定: 捕獲したketeは右のkichwa A8から蒔き始め、反時計回りに進みます。
- 根拠状態: A
- 根拠: R-002, pp. 164–165、R-003, Issue 4, pp. 21–22。

### E25: namua中央部の最初の捕獲

- 部分局面図: `A4=2 ↔ a4=3 / namuaの手の開始`
- 判定: A4はkichwaでもkimbiでもないため、a4の3個を左右どちらのkichwaから蒔くか選べます。
- 根拠状態: A
- 根拠: R-002, pp. 164–166、R-003, Issue 4, pp. 21–22。

## relay sowingとtakata

### E26: 占有穴でrelay sowingを続ける

- 部分局面図: `3個を蒔く → 終点A6には元から2個`
- 操作図: `最後の1個でA6=3 → A6の3個すべてを取る → 同じ方向の次穴から蒔く`
- 判定: 捕獲や特別な停止条件がなければ、同じ手を継続します。
- 根拠状態: A
- 根拠: R-002, p. 165、R-003, Issue 4, pp. 21–22。

### E27: 空穴で手を終える

- 部分局面図: `3個を蒔く → 終点B6=0`
- 操作図: `最後の1個でB6=1 → 終了`
- 判定: 元が空だった穴ではrelay sowingを行いません。
- 根拠状態: A
- 根拠: R-002, pp. 164–165、R-003, Issue 4, pp. 21–22。

### E28: takataの途中では捕獲しない

- 部分局面図: `takata中の終点A4が占有穴になり、a4にもketeがある`
- 判定: 形だけ見れば向かい合っていますが、takataは手全体が非捕獲です。a4を取らず、通常のrelay sowingを続けます。
- 根拠状態: A
- 根拠: R-002, p. 165。

## nyumba・takasia・終局

### E29: namuaの捕獲手が所有中nyumbaへ到達する

- 部分局面図: `namuaの捕獲手中 → {A5=6 所有中}へ最後の1個 → A5=7 ↔ a5=0`
- 判定: 捕獲できないため、A5で止まって所有を保つか、A5の全7個を取って蒔き、所有を失うか選べます。
- 根拠状態: A
- 根拠: R-002, pp. 165–167、R-003, Issue 5, pp. 22–23。

### E30: takasia対象穴でrelay sowingを止める

- 部分局面図: `mtaji / takasia対象と判定済みのA4へrelay sowingの最後の1個が入る`
- 判定: A4の全keteを取り上げず、そこで手を終了します。
- 根拠状態: B
- 根拠: R-002, p. 167。takasia成立前の完全局面はR-001照合とPhase 5後続検証の対象です。

### E31: 相手前列を空にして勝つ

- 部分局面図: `namua / A4=1 ↔ a4=3 / 相手前列はa4だけが占有 / 手元=1+`
- 操作図: `手元からA4へ1個 → a4の3個を捕獲 → 相手前列8穴がすべて0`
- 判定: 手の途中でも、この時点で相手が敗北します。
- 根拠状態: A
- 根拠: R-002, p. 164、R-003, Issue 4, p. 21。

### E32: 捕獲手なしと合法手なしは異なる

- 部分局面図: `mtaji / 捕獲手なし / A4=2`
- 判定: A4から合法なtakataができるならゲームは続きます。「捕獲できない」だけでは敗北しません。
- 根拠状態: A
- 根拠: R-002, pp. 165, 167、R-003, Issue 4, pp. 21–22。
